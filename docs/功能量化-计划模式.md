# 计划模式（2026-11-07）

`plan` 先让模型给出带 `depends_on` 的步骤。用户确认后才进入执行；拒绝、取消或非交互且没有 `--yes` 时不调用工具。彼此没有依赖的只读步骤放进同一批，由线程池同时读取。修改和验证仍按依赖逐项执行。

并行和串行耗时来自同一次离线假模型运行。两个 `read_file` 各睡眠 0.2 秒。并行墙钟是两次调用最早开始到最晚结束；串行是紧接着两次同样的 `sleep(0.2)`。

```sh
python -X utf8 -c "import json; from tests.core.test_planning import measure_parallel_reads; print(json.dumps(measure_parallel_reads(), ensure_ascii=False))"
```
