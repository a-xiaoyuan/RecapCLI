# 分层记忆（2026-11-07）

短期记忆是当前会话的对话，换一个会话就看不到上一段消息。长期记忆是项目事实，写在工作区 `.recapcli/facts/facts.sqlite3`。写入时用现有词法切词（中文双字、英文标识符），召回时在 SQLite 里按查询词重合条数取 top-k。

数字来自种子 `20261107` 的 40 条事实、每条一次查询，k = 3。插入顺序被种子打乱。查询是该条独有的 `factkeyNNN`。

```sh
python -X utf8 -c "import json; from tests.storage.test_facts import measure_recall; print(json.dumps(measure_recall(), ensure_ascii=False))"
```

```json
{
  "seed": 20261107,
  "facts": 40,
  "k": 3,
  "hits_at_1": 40,
  "hits_at_k": 40,
  "retained": 40,
  "recall_seconds": 0.0036796360000153072
}
```

| 项目 | 数值 |
| --- | --- |
| 事实条数 | 40 |
| top-1 命中 | 40/40 |
| top-3 命中 | 40/40 |
| 命中率 | 100% |
| 重新打开数据库后仍能 top-1 召回 | 40/40 |
| 跨会话保留率 | 40/40 = 100% |
| 40 次召回耗时合计 | 0.0036796360000153072 秒 |
| 单次平均 | 0.0036796360000153072 / 40 = 9.199090000038268e-05 秒 |

耗时只包住这 40 次 `recall`，不含插入和重开。另有测试确认新会话的短期对话是空的，而上一会话写入的事实仍会被本轮提示词从 SQLite 召回。
