# 检查点与 /rewind（2026-11-07）

在 `65189d2` 的 `/undo` 之外，每轮任务写文件前自动留下检查点。同一轮里每个文件只记录第一次改动前的原文。`/undo` 仍按编辑组撤回；`/rewind` 回到最近一轮尚未回退的检查点。文件内容和检查点结束时的校验不一致时，整次回退拒绝，不改文件。

数字来自种子 `20261107` 的 40 次离线试验，命令是：

```sh
python -X utf8 -c "import json; from tests.tools.test_checkpoints import measure_rewind; print(json.dumps(measure_rewind(), ensure_ascii=False))"
```

```json
  "clean_restored": 28,
  "dirty_refused": 12,

  "rewind_seconds": 0.07566149599983873

```

耗时只包住回退调用本身，不含建目录和写入。约 25% 的试验在回退前改掉本轮写过的文件，用来确认拒绝路径。

`tests/tools/test_checkpoints.py` 有 4 个测试：多稿只保留第一份原文、`/rewind` 只回最近一轮、代理一轮自动建检查点、以及上面这 40 次试验。
